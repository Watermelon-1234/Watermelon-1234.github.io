拆解GoodNote以解決輸出PDF後螢光筆遮擋問題

（法老的歌有夠好聽😭）

前言

這其實也不是我的問題畢竟我也沒有在用 GoodNote 。雖然那咖軟體手感是真的很好，但是我才不會花錢在那個訂閱費用。但不得不說他的防盜版真的做的很好，唯一流出的盜版不但不是最新還只能用 jailbreak 開（平板沒辦法越、版本太新了）。

某個朋友他直屬傳給他的微積分筆記在 PDF 檔裡面螢光筆都會擋住後面的字發現動求助。而且沒有訂閱的 goodnote 匯入不了（他說的），我一個手癢就把檔案要過來了。

災情：

分析 / 查資料

拿到的檔案是 .goodnote 後綴，然後我猜他就是一種壓縮檔之類，如果是的話那這個可能有人作過正確 viewer 畢竟壓縮檔算好分析的

超好笑還真是

一開始的想法是直接看看有沒有 goodnote viewer

Goodnoteshttps://web.goodnotes.com/home

發現官方就有網頁版，但是他只接受 150 mb 以下的，所以沒辦法用。檔案比較小的可以試試看。

GitHub - RobinSp5/FileConverter: A lightweight tool to convert GoodNotes (.goodnotes) documents into shareable PDF files.https://github.com/RobinSp5/FileConverter

這個更是完全沒有用，因為他只支援非手寫的地方，那我就不需要用 goodnote 開了吧

最後找到這個，看簡介應該是有靠 AI Vibe 出來的，有點存疑但也沒東西可以用了就死馬當活馬醫

GitHub - Kaih1825/parser-for-goodnotes: The document parser for goodnoteshttps://github.com/Kaih1825/parser-for-goodnotes

他有一個 live demo：

Document Parser for GoodNotes · Independent Vector SVG & PDF Viewerhttps://kaih1825.github.io/parser-for-goodnotes/?lang=en

看起來可能是用 web assembly 處理轉換的功能，可能檔案太大了我丟進去就停止回應了😭

readme 寫說他有 cli，然後我覺得這種複雜的分析 grok 應該比較擅長我就 clone 下來的同時把 repo 丟給 grok
加上一些爬文，決定把檔案都先轉成 svg ，向量圖的特性說不定寫個 script 就可以把螢光筆直接刪掉之類。

(記得裝 uv )

成功的生出一卡車的 SVG 了，雖然沒有像是一開始一樣全部遮住，但是還是沒有辦法閱讀
