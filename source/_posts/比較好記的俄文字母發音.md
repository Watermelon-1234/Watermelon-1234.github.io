# 子音
## 幾乎就是英文字母

## 把組合的發音變成一個單字
- -sh：**ш**
	- 發音：`sh`
- -ch：**Ч**
	- 發音： `che` ：че
- -ts：**Ц**
	- 發音：``ce``：це
- -sch：**Щ**
	- 發音：``sh-ch``

## 希臘字母
- Δ（Delta-**d**）：**Д**（de（дэ））
- Λ（Lambda-**l**）：**Л**（El (эль / эл)）
- Φ（Phi-**f**）：**ф**（ef）
- Γ（Gamma-**g**）：**Г**（Ge）
- Π（Pi-**p**）：**П**（Pe）

## 長得像是英文字母
- Б = B
- З = Z （草寫）
	- ![[(9) How To Read Russian In 9 Minutes (Seriously)-1793462852288.webp|58]]
- Р(Er) = R(eng)
- Ж = JE

## 長得像是英文別的字的
- Х = H（ENG）
- С = S（hard（英文裡面的 C 有軟的跟硬的 ））
- Н = N（ENG）
- В = V（eng  ）

# 母音

| 西里爾字母 | 標準發音 (IPA) | 英文長母音 / 短母音對應                    | 英文單字範例              |
| ----- | ---------- | -------------------------------- | ------------------- |
| **А** | [a]        | **短 A** (法式/西式 a) 或 **長 A 的前半音** | f**a**ther          |
| **И** | [i]        | **長 E**                          | m**ee**t, s**ee**   |
| **Э** | [e]        | **短 E**                          | b**e**d, m**e**t    |
| **О** | [o] / [ɔ]  | **短 O** (或不捲舌的長 O)               | n**o**t, m**o**re   |
| **У** | [u]        | **長 U** (帶有 oo 的音)               | r**oo**m, fl**u**te |


##  Й й：Y(short i)
- **Й+А = Я（yah））**
- **Й+Э = Е（yeh））**
- **Й+О = Ё（yo））**
- **Й+У = Ю（yoo））**

Ы：/i/唸起來像ooy
